# 사용 안내

현재 버전: 0.9.7. 사용자 데이터와 원본 이미지는 별도로 보존합니다.

## 작업별 최상단 탭과 노트 저장 (0.9.7)

최상단 **파일 탐색 / 이미지 라이브러리 / 노트** 탭으로 작업을 구분합니다. 기존 모드 드롭다운은 숨기고, 이미지 라이브러리 내부의 **갤러리 / 큰 미리보기** 탭으로 보기만 바꿉니다.

- 노트 목록·폴더·검색·다중 문서·버전 복원·보관·BMK 추가 필드·JSON 기능은 노트 탭으로 분리했습니다. 이미지 작업 프롬프트와 독립 노트를 오갈 때 각각의 내용/커서/텍스트 스크롤 및 실행 취소 문서를 유지합니다. 이미지의 미완료 크롭 등 편집 결과도 탭 이동만으로 버리지 않습니다.
- 이미지의 원본/작업 프롬프트/태깅 화면에서 **노트에 저장…**을 누르세요. 파일 탐색 화면에도 저장 버튼이 있습니다. 파일 탐색은 읽은 원본 프롬프트/네거티브만 제공하며 라이브러리에 자동 등록하지 않습니다.
- 저장 대화상자에서 폴더를 고르거나 `캐릭터/의상`처럼 직접 입력하고, 새 노트 또는 해당 폴더의 기존 노트를 선택합니다. 기본은 새 노트입니다. 원본 프롬프트·네거티브, 작업 프롬프트·네거티브, 현재 태깅 목록에 표시된 추정 태그 중 필요한 내용을 선택하고 저장본을 편집할 수 있습니다.
- 기존 노트에는 뒤에 추가하며 덮어쓰지 않습니다. 여러 출처를 같은 필드에 넣으면 구분 제목을 표시합니다. 원본 이미지 경로/출처를 메모와 `_studio_image_transfers`에 남기며, 저장본을 수정했다면 편집 표기를 붙입니다. 원본 이미지와 원본 메타데이터는 변경하지 않습니다. 기존 노트의 미지원 추가 필드도 유지합니다.
- 저장 후 현재 이미지 작업을 유지하고 **저장한 노트 열기**로 이동할 수 있습니다. 독립적으로 새로 만든 노트에는 열려 있던 이미지의 출처를 자동 부여하지 않습니다.
- 반대 방향은 노트 탭의 **현재 이미지의 작업 프롬프트로 보내기…**입니다. 대상 이미지 경로를 확인하고 추가/교체/취소를 선택합니다. 프롬프트와 네거티브만 보내며 텍스트 실행 취소를 지원합니다. 대상 이미지는 이미지 라이브러리에서 먼저 열어 두세요.
- Ctrl+S는 노트 화면에서는 노트 저장, 이미지 화면에서는 작업 텍스트 저장입니다. 이미지 내보내기는 별도 버튼을 사용합니다. 탭 사이의 자동 양방향 동기화는 하지 않습니다. 마지막 최상단 탭과 열린 노트는 재시작 때 복원하며 실행 취소 이력은 현재 실행 동안 유지합니다.

## 폴더 탐색 개선 (0.9.6)

- 폴더 첫 진입 시 썸네일·파일명이 잘리거나 빈 채로 남던 배치 문제를 수정했습니다. 이미지/파일명 영역을 고정하고 썸네일 완료 때 모델 갱신을 알립니다. 슬라이더나 창 크기를 다시 조절할 필요가 없습니다.
- 왼쪽 탐색 창에서 드라이브와 폴더를 펼쳐 이동할 수 있습니다. 홈·바탕 화면·다운로드·사진 및 저장한 경로는 빠른 이동에 표시됩니다. 폴더 트리는 필요한 경로를 비동기로 읽으며 파일 편집 기능은 비활성입니다.
- 주소 이동과 폴더 트리 선택은 같은 뒤로/앞으로 기록을 사용합니다. 현재 폴더를 트리에서 펼쳐 표시합니다. 세 패널의 폭을 조절할 수 있으며 저장 후 재실행에 복원됩니다. 0.9.5의 두 패널 설정은 새 기본 폭으로 전환합니다.

| 조작 | 기능 |
|---|---|
| 갤러리에서 Ctrl + 마우스 휠 | 썸네일 크기 조절 (64~320px, 한 눈금 16px) |
| Alt + ← / → | 뒤로 / 앞으로 |
| Alt + ↑ | 상위 폴더 |
| Alt + D 또는 Ctrl + L | 주소창 선택 |
| Ctrl + F | 현재 폴더 이름 검색 |
| F5 | 현재 폴더 새로고침 |
| 갤러리에서 Enter / Backspace | 선택 폴더 열기 / 뒤로 |
| 갤러리·트리의 마우스 뒤로/앞으로 버튼 | 뒤로 / 앞으로 |
| Ctrl·Shift + 클릭, Ctrl + A | 갤러리 다중 선택 / 전체 선택 |

이 단축키는 폴더 탐색 화면 안에서 동작합니다. 주소창의 Backspace는 일반 텍스트 편집으로 유지됩니다. 원본 삭제·이동·이름 변경, 파일 복사/붙여넣기, 가상 셸 항목(휴지통 등)은 포함하지 않습니다.

## 폴더 탐색 모드 (0.9.5)

상단 화면 모드에서 **폴더 탐색**을 선택하세요. 주소창에 디스크 폴더 경로를 입력하고 Enter를 누르거나 `폴더 선택`으로 지정합니다. 뒤로·앞으로·상위 폴더·새로고침을 지원하며 폴더는 더블클릭으로 이동합니다.

- 현재 폴더의 하위 폴더와 지원 이미지(PNG/JPEG/WebP/BMP/TIFF/EXR)를 표시합니다. 하위 폴더 내부를 재귀 검색하지 않습니다. 폴더 접근 실패는 화면에 표시하고 마지막으로 열린 목록을 유지합니다.
- 이름 검색과 이름·수정일·파일 크기 오름/내림차순 정렬, 64~320px 썸네일을 지원합니다. 폴더는 항상 앞에 표시합니다.
- 이미지 선택 시 기존 확대/이동/보간 기능을 사용하는 별도 원본 미리보기와 프롬프트·네거티브·전체 정보 탭을 보여줍니다. 기록되지 않은 프롬프트는 추측하지 않습니다.
- 탐색·미리보기는 라이브러리 등록이나 기존 편집 작업을 변경하지 않습니다. 여러 이미지를 선택해 `선택 이미지를 라이브러리에 추가`를 누르면 명시적으로 등록합니다. 기존 작업 이미지는 그대로 유지됩니다. 상단 `이미지 추가`/`폴더 추가`는 기존 라이브러리 등록 기능입니다.
- 목록 제거·원본 삭제·이름 변경·파일 이동 기능은 제공하지 않습니다. 원본 폴더에는 파일을 쓰지 않습니다.
- `☆ 경로 저장 / 해제`로 현재 경로를 즐겨찾기에 넣거나 뺄 수 있습니다. 마지막으로 열린 폴더·즐겨찾기·썸네일 크기는 사용자 데이터 폴더에 저장됩니다. 탐색 기록의 뒤로/앞으로 목록은 현재 실행 동안 유지됩니다.
- 썸네일은 필요한 카드부터 백그라운드 생성하며 메모리 아이콘 128개, 대기 128개, 배치 8개입니다. 사용자 데이터의 `folder-thumbnails` 파생 캐시는 256 MiB로 제한하며 오래된 캐시만 정리합니다. 큰 원본의 첫 미리보기는 파일 읽기에 시간이 걸릴 수 있습니다.
- 파일 변경 사항은 `새로고침`으로 반영합니다. 자동 폴더 감시나 재귀 탐색은 이 모드에 포함하지 않았습니다. 사용자 데이터 폴더 복사 시 경로 설정과 캐시도 함께 보존합니다.


## 후속 탐색 기능 (0.9.4)

- **검색 자동완성**: 검색창에 두 글자 이상 입력하면 현재 검색 범위에서 후보를 제안합니다. 원본 프롬프트·네거티브·작업 텍스트·추정 태그를 구분하며 UI를 막지 않고 집계합니다.
- **날짜 / 타임라인**: 파일 수정일 또는 명시된 생성 관련 날짜를 골라 월별로 탐색하거나 시작일·종료일을 지정합니다. `날짜 미상만 보기`도 있습니다. 월을 클릭하면 그 월의 범위를 선택하며 저장된 검색에도 날짜 조건이 포함됩니다. 생성 관련 날짜는 Creation Time·XMP CreateDate·EXIF DateTimeOriginal 등 원문 날짜를 사용합니다. EXIF 촬영일이 남아 있다면 그 날짜가 표시될 수 있어 실제 AI 실행 시각과 같다고 보장하지 않습니다.
- **컬렉션 드롭 영역**: 버튼을 눌러 펼친 뒤 갤러리에서 선택한 카드들을 컬렉션 이름 위로 끌어 놓습니다. 원본 위치는 바뀌지 않습니다. `관리 → 컬렉션 삭제`는 소속 정보만 삭제하고 `마지막 컬렉션 삭제 복원`으로 재시작 후에도 한 건을 복원할 수 있습니다.
- **큰 썸네일**: 갤러리 크기를 최대 512px로 조절합니다. 160px를 넘기면 필요한 원본부터 별도 썸네일을 만들며 원본을 확대 저장하지 않습니다. 작업 화면은 64px를 유지합니다. 큰 썸네일의 메모리·디스크 캐시는 제한되며 기존 작은 썸네일을 크게 늘리는 방식이 아닙니다.
- **유사 이미지**: 현재 갤러리 결과의 시각적 유사 후보를 묶습니다. 허용 거리가 작을수록 엄격합니다. 그룹을 선택해 갤러리에서 확인하고 `모두 해제`로 전체 목록에 돌아갑니다. 모양·평균색·종횡비에 따른 근사 후보이며 동일 파일 판정이나 자동 삭제를 하지 않습니다.
- **의미 검색**: `공식 모델 다운로드 / 이어받기`로 모델을 한 번 설치하거나 이미 설치한 폴더를 선택합니다. 약 128 MB이며 다운로드 이후에는 오프라인 CPU 검색입니다. 한국어 문장으로 영어 프롬프트도 검색할 수 있습니다. 원본 긍정·작업 프롬프트·추정 태그 중 하나를 고르고 현재 갤러리 범위에서 관련도순 상위 100개를 확인합니다. 텍스트와 이미지는 외부에 전송하지 않습니다.
- 의미 검색은 **이미지 픽셀이 아닌 텍스트의 의미**를 검색합니다. 첫 128토큰을 사용하고 선택한 출처에 텍스트가 없는 파일은 제외합니다. 원본 프롬프트를 복원하거나 추측해 채우지 않습니다. 점수는 정답 확률이 아닙니다. [공식 다국어 모델 카드](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)를 참고하세요.
- **작업 목록**: 색인·검색·썸네일·의미 검색·모델 다운로드 등 진행 상태와 최근 완료 작업을 확인하고 지원 작업을 취소합니다. 색인은 남은 배치도 멈추며 이미지/폴더를 다시 열면 재개합니다. 큰 썸네일 취소 후에는 크기를 조절하거나 갤러리 모드에 다시 진입해 재개합니다. 저장·내보내기처럼 중간 취소가 안전하지 않은 작업은 완료를 기다립니다.

의미 검색 모델 가중치는 실행 패키지에 포함하지 않습니다. 설정·분류·벡터·썸네일 캐시는 사용자 데이터 폴더에 저장하고, 폴더 이전 시 운영 경로를 재연결합니다. 자세한 지원 범위·제한은 UI_UX_IMPLEMENTATION.md에 있습니다.


## 사용자 데이터 폴더 지정 (0.9.2)

`설정 → 사용자 데이터 폴더 변경…`에서 원하는 폴더를 선택합니다. 예: `H:\BMK-AI-Studio\user` 또는 별도 드라이브의 `BMK-UserData`.

1. **현재 데이터를 복사하고 사용**: 비어 있는 폴더를 선택합니다. 노트/작업 텍스트/태그 DB, 크롭 의존 이미지, 편집 보관·자동 복구본, 와일드카드, 내보내기, 앱이 다운로드한 모델 등 현재 데이터 폴더 전체를 복사합니다. 원래 폴더는 보존합니다.
2. **기존 데이터 폴더 사용 / 새로 시작**: 이미 사용하던 BMK 데이터 폴더 또는 빈 폴더를 선택합니다. 현재 데이터와 병합하지 않습니다. 현재 작업은 기존 폴더에 보관합니다.
3. `저장 후 종료`를 누르면 현재 작업을 저장하고 전환을 준비합니다. 앱을 다시 실행하면 선택한 폴더를 사용합니다.

폴더 감시·태깅·다운로드 등의 작업이 끝난 후 전환하세요. 다른 버전의 BMK AI Studio도 종료해야 합니다. 0.9.2는 같은 데이터 폴더를 사용하는 중복 실행을 차단합니다. 진행 중인 복사에서는 창이 반응하며 상태를 표시하고 완료를 기다립니다.

복사 시 SQLite는 백업 API로 저장하고 파일은 SHA256을 확인합니다. 데이터 폴더 내부의 클립보드 원본, 크롭/마스크 의존 파일, 보관 기록, 대기열·창 상태 및 앱 내보내기 기록의 운영 경로를 새 위치로 연결합니다. 원본 메타데이터와 노트 본문/미지원 필드는 그대로 보존합니다. 외부 원본 이미지·외부 모델은 복사하거나 이동하지 않습니다. 내부 모델 경로가 바뀌면 일부 추론 캐시는 다시 계산할 수 있습니다.

경로 선택만 `%LOCALAPPDATA%\BMK-AI-Studio-config\data-location.json`에 저장합니다. 사용자 데이터 자체는 선택한 폴더에 있습니다. 기본 폴더는 `%LOCALAPPDATA%\BMK-AI-Studio`입니다. 기본 위치로 돌아가려면 그 폴더를 기존 데이터 사용 방식으로 선택하세요.

고급 실행 옵션: `BMK-AI-Studio.exe --user-directory "H:\BMK-AI-Studio\user"`. 우선순위는 **실행 옵션 → BMK_STUDIO_DATA 환경변수 → 설정에서 선택한 폴더 → 기본 폴더**입니다. 실행 옵션/환경변수가 적용된 실행에서는 설정의 폴더 변경이 비활성화됩니다.

지정한 드라이브/폴더가 사라지면 새 빈 라이브러리로 자동 전환하지 않고 안내합니다. 저장된 설정 경로를 열 수 없으면 시작 화면에서 다른 폴더를 선택할 수 있습니다. 실행 옵션/환경변수 경로 오류는 그 지정을 수정해야 합니다.

복사 실패 시 기존 경로 설정을 유지합니다. 불완전한 복사 폴더에는 표시 파일을 남겨 잘못 열지 않도록 막으며, 새 빈 폴더를 골라 다시 시도할 수 있습니다. 기존 폴더 사용은 기록을 그대로 여는 기능이므로, 탐색기로 옮긴 폴더의 과거 절대 경로를 자동 추측하지 않습니다. 폴더 이전은 앱의 복사 후 전환 방식을 권장합니다.


## 크롭 UX (0.9.1)

`편집 → 크롭 영역 편집`을 켜고 중앙 이미지에서 드래그합니다. 프레임 바깥은 55% dim 처리하고 안쪽은 원래 밝기로 유지합니다. 삼분할선과 네 모서리 앵커를 표시하며, 앵커의 화면 크기는 확대 배율과 관계없이 일정합니다.

- 영역 안쪽 드래그: 크기 유지 이동. 네 모서리 드래그: 반대 모서리를 고정한 크기 조절.
- 바깥 또는 Shift+드래그: 새 영역. `새 영역` 버튼도 사용할 수 있습니다.
- 스냅: 끄기(1px), 8/16/32/64px. 드래그·크기 조절·숫자 입력에 적용하며 다음 실행에도 유지합니다. Alt를 누른 동안 드래그 스냅을 해제합니다.
- X/Y/너비/높이는 드래그 중 실시간 반영됩니다. 숫자를 입력하고 Enter/포커스 이동으로 확정하면 프레임에도 반영합니다. 비율 고정 상태에서는 너비/높이를 함께 보정합니다.
- 휠: 확대/축소. Space+드래그 또는 가운데 버튼 드래그: 화면 이동. 방향키: 스냅 단위 이동, Shift+방향키: 10배. Esc: 진행 중인 드래그 취소.
- 이미지 경계와 선택한 종횡비를 스냅보다 우선합니다. 비율의 파생 축은 정수 픽셀 반올림 때문에 최대 약 1px 차이가 날 수 있습니다. 스냅 변경만으로 현재 영역을 강제로 바꾸지는 않습니다.

프레임 조절은 원본/작업본 픽셀을 바꾸지 않습니다. `크롭 적용`을 눌러야 현재 작업본에 적용되며 실행 취소와 기존 스티치 흐름을 유지합니다. 적용 후 다음 크롭은 새 작업 이미지의 전체 범위에서 시작합니다.
